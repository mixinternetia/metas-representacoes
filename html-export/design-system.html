1. Introdução

O Design System do Metas Representações estabelece os padrões visuais e comportamentais utilizados em todo o sistema.

Todos os novos módulos e telas devem utilizar os componentes documentados nesta página sempre que possível. Esta não é uma tela operacional do ERP: todos os dados aqui são fictícios e servem apenas como referência visual.

Regra principal

Não criar componentes visuais novos quando já existir um componente equivalente no Design System. Priorizar reutilização.

Fundamentos
Cores, tipografia, espaçamentos, bordas e ícones.
Componentes
Botões, campos, tabelas, feedback e navegação.
Padrões de tela
Listagem, cadastro em abas, visualização e filtros.

28. Regras de uso

Checklist obrigatório antes de publicar qualquer tela nova.

01Utilizar sempre os componentes existentes antes de criar um novo.
02Manter a mesma hierarquia visual em todas as telas.
03Não criar novas cores sem necessidade — usar os tokens semânticos.
04Não utilizar fontes diferentes da família padrão.
05Manter os mesmos espaçamentos da escala de 4px.
06Utilizar os mesmos padrões de botões e suas variantes.
07Utilizar os mesmos padrões de tabelas (DataTable).
08Utilizar os mesmos padrões de formulários (FormSection + Field).
09Manter consistência entre todos os módulos do sistema.
10Qualquer novo componente deve ser incorporado ao Design System.
